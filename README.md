# Power24 - Solar Energy & Rooftop Solutions

Power24 is a comprehensive web application for booking solar rooftop installations, customized solar combo kits, and purchasing solar equipment (Panels, Inverters, LiFePO4 Batteries) with live PM Surya Ghar subsidy calculations and an Admin Management Dashboard.

## Features
- **Solar Complete Kits (1kW to 10kW)**: Live capacity rate configuration and PM Surya Ghar Govt Subsidy calculations.
- **Custom Solar Kit Builder**: Interactive step-by-step custom kit configurator (Panel, Inverter, Battery, Structure, Wiring, Protection, Installation).
- **Product Catalog & Details**: High-resolution gallery, specs, warranties, and direct booking/orders.
- **Order & Booking Management**: User & Admin tracking with detailed itemized cost breakdowns.
- **Admin Dashboard**: Real-time product pricing, banner management, booking & order status tracking.

## Tech Stack
- React + Vite
- Tailwind CSS / Vanilla CSS
- Lucide React Icons
- LocalStorage persistence
